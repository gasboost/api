# gasboost/api

Packages for Google Apps Script and API clients.

## Packages

- [`@gasboost/gemini`](./packages/gemini/README.md): Gemini Interactions API client.
- [`@gasboost/openai`](./packages/openai/README.md): OpenAI Responses API client.

pnpm install
